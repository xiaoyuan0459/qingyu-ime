一、关于本应用的许可

本应用整体以 GPL-3.0-only 发布。该协议允许自由使用、修改与商业分发，要求保留版权与许可声明，
并要求衍生作品同样以 GPL-3.0-only 发布。

选择 GPL-3.0-only 的原因是随包分发的默认词库（雾凇拼音 rime-ice）本身即为 GPL-3.0-only：
GPL 与 Apache-2.0 等宽松许可单向不兼容（宽松许可的代码可纳入 GPL，反之不可），
因此词库继续内置分发时，整体须采用 GPL-3.0-only。本应用未对第三方内容施加额外限制。

应用内各组件许可不同，以「第三方开源声明」页面为准。手写识别使用本工程自训练的模型，随项目整体
以 GPL-3.0-only 分发；语音使用的 Vosk（Apache-2.0）保留各自许可，不随应用整体协议改变。


二、上游项目

本工程的界面骨架与 Android 输入框架源自开源项目 YuyanIme（https://github.com/gurecn/YuyanIme）及其 SDK 子模块，许可为 BSD-3-Clause，版权人为王莹（gurecn）。按 BSD-3-Clause 的要求，本应用保留该版权声明、许可条件与免责声明；本应用与原作者之间不存在背书或担保关系。

需要区分两件事：Yuyan 以 BSD-3-Clause 授权的是它有权授权的自有源码，这不代表整个应用包都因此是 BSD-3。本应用随包分发的词库与原生引擎等第三方组件保留各自的许可，详见「第三方开源声明」。随仓库提供的继承预编译词库二进制因来源无法核验已不再打入本应用。

自 2026-09 起，Rime 引擎接入层、词库分发机制、手写识别引擎、品牌与图标均已在本仓库内重写或替换。JNI 绑定层原继承自同文 Trime（GPL-3.0-or-later）并存在来源不确定性，已按语义重写为 RimeSession / EngineTypes，迁移与决策依据见仓库 MIGRATION.md 与 docs/adr/0004-整体GPL-3.0-only开源路线与上游许可义务.md。

语音识别使用 Vosk（https://github.com/alphacep/vosk-api，Apache-2.0）。中英文小模型不随 APK 分发，由用户首次开启“离线语音”时从 https://alphacephei.com/vosk/models 下载，可删除。

手写识别使用本工程自训练的模型 qingyu-hw-image-v1：语料由 OFL-1.1 字体离线渲染生成，推理层与模型随项目整体以 GPL-3.0-only 分发；类别数、字表哈希与产物 SHA-256 记录在模型资产的 model-manifest.json，来源与致谢见仓库 CREDITS.md 与 LICENSING.md。

五、自行构建

需要 JDK 21、Python 3.11+、Git 和 Android SDK，精确版本见 docs/DEVELOPMENT.md。

	git clone https://github.com/xiaoyuan0459/qingyu-ime.git
	cd qingyu-ime
	python tools/bootstrap-native-deps.py
	.\gradlew.bat :app:assembleOfflineDebug        # Windows
	./gradlew :app:assembleOfflineDebug           # Linux / macOS

原生依赖按 tools/native-deps.lock.json 固定 revision 与 SHA-256，构建脚本不会覆盖已有依赖目录。构建记录、版本号与已知限制见仓库文档索引 docs/README.md。
