# 轻语输入法 0.2.1-dev

0.2.0-dev 之后的修复版本，处理五条用户反馈 issue，并把键盘与参考输入法逐像素对齐。输入链路、词库与数据格式没有变化，可直接覆盖安装同包名的旧 0.2.0-dev Release。

## 修复

- 悬浮键盘：窗口与可触摸区域只覆盖键盘本体，右侧不再吃掉屏幕下方内容，候选第五个词不再露出一角；切换输入框或改设置后按当前布局重建缓存键盘。
- 悬浮键盘选拼音前缀时 `KeyRecordStack` 越界崩溃（`removeAt(-1)`）已修。
- 文本编辑“选择”键有开启态：有选区时键面转强调色，与顶栏 ‹ 同一返回语义。
- 工具箱反馈项一次插入完整设备信息（系统版本、应用版本、构建时间与提交、品牌型号、处理器架构、屏幕与字体缩放）；issue 模板的三项设备字段合并为一个输入框。
- 手写半／全屏切换键按当前形态显示，主字深色、切换目标副字浅灰；右侧删除／符号列与底排末键同宽同左对齐。
- 清空剪贴板历史改到后台执行，带“正在清空”状态条与失败重试，不再阻塞触摸。

## 优化

- 剪贴板列表固定为单列扁平行（移除网格／瀑布流设置），每行底部 1dp 细分割线、行高 52dp、长文本最多两行省略。
- 剪贴板长按改为竖向动作卡，在面板内水平、垂直居中，不再贴着被长按的条目展开；高度超出时在卡片内滚动。
- 展开候选面板：每个候选固定一格、4 列等宽，长短词靠字号自动缩放或省略，不再给前两项双宽、也不再按长度跨列；面板按 3–4 个完整行均分高度，最后一行不再被系统手势区截断。
- 面板侧栏配色对齐参考：左列与候选格同为键面底色，只有右侧操作列是浅灰；左列改为展示候选实际覆盖的读音（含别读），点选即按该读音过滤。
- 注音复用打字时键盘上方的标签：展开态顶栏高度归零、面板接管“候选栏 + 键盘区”，标签位置与打字时一致，背后是宿主页面背景，不再压一条键盘底色灰带。
- 键面标点改按墨迹水平居中：功能帽与角标的“，”“。”“！”“＠”不再偏左，26 键、九键、数字、符号、手写共用同一套绘制。
- 按键效果改为设置首页与工具箱直接弹出的五挡小卡片（音量／触感：系统、关闭、弱、中、强），不再进二级页面；旧页面与导航入口删除。
- 新增不含输入内容的键盘操作日志：生命周期、输入框类型、键盘切换、布局重建、浮窗拖动、insets、面板进出、文本编辑动作、剪贴板动作与反馈挡位，256 KB 轮转，随“关于 → 导出诊断日志”一起打包。

## 验证

MEIZU 18 Pro / Android 13 / arm64（1080×2400、440dpi）真机逐项对照参考输入法截图：剪贴板分割线与长按卡位置、面板整行分页与侧栏色值、注音标签位置、底排标点居中。`imesdk` JVM 单测与 `:app:lintOfflineDebug`、`:app:lintOfflineRelease` 通过。Release（R8）包真机冷启动、组合上屏、展开面板与剪贴板长按实测通过，不以 debug 构建成功代替验收。

## 已知边界

- 左列读音取自引擎候选注释，词库没有相应变体读音时不会像参考输入法那样列出纠错拼音（如 `lou` 只给 `lou`）。
- 长按动作卡比参考多一项“置顶”，因此卡片更高、上下留白更小。
- 数据库沿用 v8（含 0.2.0-dev 的反馈信息表），本版无新增迁移。

## 打包

APK 仅 arm64-v8a，versionCode 2026103101、versionName 0.2.1-dev。CI 产出 debug 与 unsigned Release 工件（artifact 名 `android-build-<commit SHA>`），签名在本机用 `keystore/release.properties` 完成，私钥与口令不进入云端。Release 包名 `com.qingyu.inputmethod.offline.release` 与 debug 不同，跨包名的数据迁移仍未验收。
