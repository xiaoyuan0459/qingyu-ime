# 轻语输入法 0.2.0-dev

原生字形方案已接入：简体保留白霜原词及词频，通用繁体优先直接来源的繁体词条，原字保留古字、异体及原始码点。候选选中后直接上屏，不再经过 OpenCC 简繁词组转换。繁体未覆盖词条仍可输入，显示“·原”标记。

- 默认词库改为固定 revision 白霜，旧内置雾凇按固定身份升级，其他导入包保留。
- 联想改用后台只读前缀索引，避免争用前台输入锁，按词库、模式和引擎代次隔离缓存。
- 设置与工具栏提供简／繁／原三态，旧简繁设置一次性迁移。旧包请求通用繁体但缺少能力时明确使用原字。
- 修复源码包部署污染清单导致导入失败，以及优化 Release 的 SDK 入口和 Room 构造器被移除导致冷启动崩溃。
- CC-CEDICT 源快照、归属、修改说明和完整许可随源码及 APK 分发，OpenCC 仅供 Emoji。

真机验证：MEIZU 18 Pro / Android 13 / arm64，13 项设备用例通过，另有 91 项 JVM 测试。覆盖实际触摸、候选上屏、三模式、九种拼音布局、古字 Unicode、输入框切换、旧设置迁移与旧包导入回滚。详见[完整口径](../validation/0.2.0-dev.md)。

本版仍为预览：有限词库不保证所有古文、人名首选正确。尚未完成多 ROM、大语料首选质量、触摸显示延迟和低存储/异常断电全矩阵。没有新增长按固定字形编辑器。

APK 仅 arm64，使用已配置的发布证书。它与旧 debug 预览包名不同；保留旧安装及数据，跨包名迁移未验收。校验 SHA256SUMS.txt，构建来源、签名前后哈希及载荷核对见 release-provenance.json。CI 构建优化包，本机签名，私钥不进入云端。
