## 构建、Release 与发布边界

本地与 Actions 的构建 / lint / JVM 结果、最终提交、tag、Actions run、APK 输入输出哈希分别记录。
最终发行使用成功 tag run 的优化 unsigned APK，在本机以配置证书签名，逐文件核对签名未改动载荷；来源见随 Release 的 release-provenance.json。
正式发布状态以 GitHub Release、资产下载哈希及来源文件为准，本文不将本地构建等同于云端成功。

SDK instrumentation 覆盖真实代码与设备行为；最后一次修改回滚选项恢复后，13 项设备回归与 91 项 JVM 用例再次通过。优化 Release 以配置证书签名，逐文件载荷一致，版本 / arm64 ABI / 安装和两次设置页冷启动通过，期间该 UID 无崩溃记录。这不等于优化 Release 的全量触摸回归。

本机首次 Release 构建在 R8 阶段因 JVM 本机内存分配失败中断；关闭本任务 Kotlin 编译守护进程并限制构建堆、线程及 GC 后，Release 构建和 lint 通过。SDK debug 构建、JVM 与 lint 通过后，合并执行的 app 编译曾因临时限制的 384 MiB Metaspace 不足退出；app assembleOfflineDebug / lintOfflineDebug 以独立进程复跑成功；不将资源中断计为用例成功。
