# 0010：原生简繁词形与原字模式

日期：2026-10-30。状态：已在 0.2.0-dev 接入生产代码；设备验证边界见[本版报告](../validation/0.2.0-dev.md)。

用户约束：不用 OpenCC 词组转换；默认白霜；通用繁体，另设原字模式；离线，降低输入延迟。
本决策取代 ADR 0009 的简繁转换部分，沿用白霜、事务安装与只读联想索引。

## 决策与用户行为

直接检索原生词条，候选的字形就是提交字形。展示、选词、上屏、联想均不执行简繁改写。
不以 Unihan 逐字映射替代转换器，不通过字形黑名单删除古字或专名。

| 模式 | 已实现行为 |
| --- | --- |
| 简体 | 使用完整白霜原生词形、分表和词频。保留其中的古字及专名，不强制过滤成纯简体字集。 |
| 通用繁体 | 优先原生繁体词条。白霜原词作为低优先级回退保留，候选栏显示“·原”，提交不含标记。 |
| 原字 | 合并完整白霜与原生繁体词条，不做 Unicode 规范化或简繁改写；合法异体分别可选。 |

这是候选偏好，不是任意文本的转换器。有限词库不能保证所有古文、人名和新词的首选正确。
原生繁体词条也不是经过人工逐项审校的现代规范全集；来源标注的 variant / old variant / archaic variant
在新增词典中降权为 0.25，存在同词同音的非变体记录则恢复正常权重。所有异体保留，白霜词频不改动。
例如“臺灣”在“台灣”前，二者都可选；發／髮不折叠成一个答案。

设置页提供三选一，键盘字形按钮显示“简／繁／原”，点击循环，工具箱入口进入同一设置页。
模式由统一枚举与状态流驱动，旧布尔设置只迁移一次。没有新增长按候选固定字形或固定词条编辑器。
选择后的学习由 Rime 用户词典负责，原词和 native_hant 分库存储；简体与原字共享原词学习。

切模式通过原生接口在会话锁内更新属性，刷新一次未确认组合；已确认前缀与宿主已提交文本保持原样。
候选保留真实引擎下标，来源标记只进入 displayText，不污染实际文本或读音 comment。

## 构建与运行时

`tools/rime_native_forms.py` 生成 native_hant.dict.yaml，`tools/build-rime-pack.py` 打包实际编译产物。
每种拼音布局复用自身 algebra，分别为 native_hant 编译 prism；不跨音节表复用不兼容 prism。
隐藏编译 schema 不进入公开方案列表。pack 逐文件哈希覆盖新增词典、prism、能力元数据及两份联想索引。

SDK 的 native_script translator 根据模式选择或合并原生字典，不修改第三方 librime 源码。
Generic simplifier 注册为透传过滤器，阻断旧导入 schema 以任意 alias 启用简繁改写；
只有 qingyu_emoji 独立组件可调用保留原文的 emoji 过滤。OpenCC 库仍因 emoji 链接，不能声称完全移除了 OpenCC。
旧 t2s/s2t 过滤器、六份转换资产及 SimplifiedText 已移除，没有隐藏转换兜底。

联想使用构建时前缀索引，后台读取；原字交错合并两份原生结果，通用繁体用原生繁体索引。
缓存包含词库身份、引擎代次及模式，用户联想习惯按模式隔离；旧异步结果不能覆盖新模式。
前台输入不再承受此前 26 次逐字母引擎扫描与共享锁竞争。

笔画、通配、手写、语音、常用语与剪贴板保留来源文字；不将不具备繁体归属的结果伪装成已核验繁体。
本轮未重做手写或语音识别模型，也未独立验收其全部设备流程。

## 升级与失败恢复

旧 chinese_jian_fan_enable=false/true 原子迁移为 script_output_mode 的简体/通用繁体 ID，移除旧键。
缺少原生能力元数据的旧包请求通用繁体时进入原字模式，选择不可用模式会提示；旧包自带 simplifier 也不能恢复转换。
用户词库内容不批量改字，原始 pinyin 用户库继续使用，新增 native_hant 使用独立用户库。
这没有实现任意历史用户词库的词形分类或跨包名自动迁移。

源码包编译使用 cacheDir 下独立临时用户目录，避免 installation.yaml / user.yaml 污染包并触发严格清单拒绝。
编译失败清理临时目录，旧活动包与输入选项恢复；不放宽未声明文件校验。
旧内置雾凇只有固定 ID 与来源匹配才升级白霜，其他导入包不被替换。

## 已验证与未覆盖

本版完成 91 项 JVM 测试及 13 项 Android 真机用例，覆盖三模式精确提交、36 个词形组合、
九种拼音布局、發／髮、原字标记、组合前缀、退格、联想、旧设置迁移、旧源码包导入与回滚。
隔离包验证扩展区、兼容汉字、IVS 和 iPhone 逐码点保留；实际触摸验证候选提交、模式设置和密码输入框切换。

设备为 MEIZU 18 Pro / Android 13 / arm64；测试数据与 IME 都在私有测试命名空间，结束恢复原输入法。
性能是受控候选装配耗时，不替代触摸显示延迟；最终 Release、CI 与发布签名分别记录在本版报告和发布资产中。
未完成多 ROM 全覆盖、大语料首选质量评估、P99 长时统计、触摸显示延迟、三模式最新内存对比、
低存储/断电全矩阵及长按固定字形编辑。后续按真实词条和设备缺口增补，不以转换例外表宣称“完美”。
