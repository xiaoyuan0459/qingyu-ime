# ADR 0006：模糊音开关放在应用侧，词库包按内容定版

日期：2026-10-16。状态：已实施（全拼与九键；双拼见 [技术债](../TECHNICAL_DEBT.md)）。

## 场景与决定

搜狗魅族版的输入设置里有四组模糊音开关（zh/ch/sh↔z/c/s、n↔l、f↔h、前后鼻音），轻语按同一功能族提供开关。

上游没有「按开关启停拼写规则」的能力：librime 1.11.2 的 `algo/calculus.cc:Calculus::Parse` 只取斜杠分隔的前两段，`derive/…/$1/zh_z` 末尾的选项名被静默丢弃 —— 规则一旦编进棱镜就常开，把选项名写进 algebra 只是看起来能关。因此分两层实现：

- 词库层用 `fuzz` 而不是 `derive`。`Fuzzing` 继承 `Derivation`（保留原拼写），同时把派生拼写标成 `kFuzzySpelling` 并累加 `log(0.5)` 可信度；`dictionary.cc:compare_chunk_by_head_element` 按 `credibility + 块首权重` 合并同音块，这就是引擎原生的降权分层，不需要改词典权重或另建方案。
- 应用层 [FuzzySpellingGate](../../imesdk/src/main/java/com/qingyu/inputmethod/FuzzySpellingGate.kt) 负责「关」。`ScriptTranslator::Spell` 写进候选注释的是词库音节拼出的**真实读音**，与用户输入不一致即说明走了派生拼写；按 `'` 分音节逐段比对，每段只在「用全部规则可解释」且「用已开启的规则解释不了」时才丢弃。注释为空、段数不符、差异无法归因（按键纠错、简拼、补全、英文词表）一律保留 —— 误删别的候选比漏放一条模糊候选更糟。代价是规则表在 schema 与 Kotlin 各存一份，由 `FuzzySpellingGateTest` 解析 `pinyin.schema.yaml`／`associate.schema.yaml` 逐条钉住，只改一边即测试失败。

`emoji/inherit_comment` 随之从 `false` 改为 `true`：表情展开出的候选原本没有注释，会绕过归因、在关闭模糊音后仍然露出。

归因比的是「读音」与「敲出的形式」，两者在九键下不同形：键码组合串（`hao → GAM`）要先用 `T9PinYinUtils.pinyin2T9Key` 把读音写成键码，`FuzzySpellingGate.Encoder` 就是这个换算位，按当前方案选取（全拼恒等，九键键码）。双拼缺一张可用的「读音 → 键码」表，留作后续（见技术债）。

## 展示位与引擎下标解耦

过滤之后「列表下标 == 引擎全局下标」不再成立，而选词、空格取首项、展开面板筛选都按下标回传 `RimeSelectCandidate`。改为在装配候选时把引擎下标钉在 `Candidate.engineIndex` 上（自定义短语、联想、手写为 `-1`），`DecodingInfo.engineIndexOf(position)` 统一换算，`RimeEngine.selectCandidate` 只接受引擎下标。累积翻页用 `engineFetched` 记录已交出的候选数作为下一页起点。

[ADR 0003](0003-候选展示筛选与只读笔画反查.md) 里 `CandidatePanelState.Entry(engineIndex, …)` 的命名按新语义改为 `displayIndex`：它是 `DecodingInfo.candidates` 的位置，真正的引擎下标只在候选对象上。

## 词库包必须按内容定版

`manifest.version` 原先只跟上游 rime-ice 的发布号，改一条 algebra 不会让它变化；而 `RimePackManager.ensureBuiltinInstalled` 见到活动包就返回，于是设备上永远跑着旧词库 —— 模糊音第一轮「验证通过」实际验证的是没有该规则的包（`qingyu_probe --codes` 对比：部署版 `zong → zong:normal`，新包 `zong → zhong:fuzzy|zong:normal`）。

现在 `tools/build-rime-pack.py` 在 version 末尾追加全量文件清单摘要 `+c<sha8>`，`ensureBuiltinInstalled` 改为比较内置归档清单与活动包清单：内容不同即重装（走既有事务安装，旧包留作回滚），`id` 不同说明是用户自行导入的词库，不覆盖。

## 验证

- `FuzzySpellingGateTest`：归因矩阵（本码、单组、多组、多音节、不可归因、段数不符）＋ 与两份 schema 的 fuzz 规则逐条一致。
- `FuzzySpellingGateEngineTest`（模拟器）：棱镜常开可拿到 `中(zhong)`；关闭时展示列表不含它且变短；`总` 的钉住下标指向引擎页原位；按该下标选词上屏为「总」；打开 `zh_z` 后「中」回来且下标与当前引擎页一致。
- `qingyu_probe` 新增 `--words`（词库存储序）与 `--query`（真引擎候选＋注释），用于把排序问题变成可差分的事实：`sort: original` 曾让权重 1 的 `𭎂` 占住 `zong` 第 2 候选，改为默认按权重后消失。
