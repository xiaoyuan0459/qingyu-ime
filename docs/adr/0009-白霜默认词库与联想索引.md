# 0009：白霜默认词库与只读联想索引

日期：2026-10-29。状态：采用。

后续决策：用户要求不沿用 OpenCC 词组转换，并选择通用繁体与原字模式。
简繁方向由 [ADR 0010](0010-原生简繁词形与原字模式.md) 重新设计；下文保留该轮实现事实，
简繁部分仅为该轮历史记录；原生词形已在 0.2.0-dev 接入，见 ADR 0010 和本版验证。白霜、事务安装与联想索引仍沿用。

默认词库改为白霜 `96278d87bf29403dd16ac854e71c496ab6ee5e71`。使用该 revision
的默认分表、细胞词库和权重；不套用轻语的雾凇频率覆盖表或叠加层，不启用上游默认
注释掉的腾讯表。`corrections` 依赖上游的提示处理协议，当前客户端未实现，故不把
其中的提示文本当正文导入。方案键码、双拼、九键与笔画仍由轻语配置负责。
白霜的 GPL-3.0-or-later 与项目整体 GPL-3.0-only 组合，保留白霜许可全文和固定来源。

旧内置雾凇的 ID 与固定来源均匹配时升级到白霜，用户数据目录不变；其他 ID 的导入包
保持活动状态，旧包由现有事务存储保留用于回滚。历史版本若把自定义内容包装成旧内置
ID 和同一来源，则无法与内置包区分，升级前应导出为独立 ID 的包。

主输入仍使用 dev 已有的 OpenCC t2s/s2t 过滤器；古字、专名通过词组优先规则处理，
不恢复按字删除候选的旧实现。自动转换存在一对多歧义，不能声称覆盖所有古籍和人名。
联想及笔画通配使用 SimplifiedText 按当前开关选择相同的 t2s/s2t 数据；修复繁体模式
此前只原样返回简体词库正文的问题。旁路只展示默认转换值，主引擎还可列出转换备选。

旧联想每个末字发起 26 次引擎探测，每次最多翻 2000 个候选，并与前台按键共享原生锁。
新包在构建时按字头、源词频生成 `associate.bin`，每字最多 240 个词，展示仍最多 100 个。
索引独立于可变的用户词库，习惯排序沿用现有本地数据；不包含任何真实输入。
运行时二分读取只读文件，不加载全表，不申请网络权限，不占用 librime 锁。
没有索引的导入包保留引擎检索；其完整拼音通过 RimeSetInput 一次设置，避免逐键重复翻译。

索引格式为大端序：8 字节 `QYAS0001`、32 位记录数、每条 32 位 Unicode 码点 / 64 位
负载偏移 / 32 位字节长度，再跟 UTF-8 换行分词负载。记录按码点递增；索引随 pack
manifest 逐文件校验。缺失、损坏或格式未知时回退旧路径；查询句柄按次关闭，换包后不保留
文件映射。新增上游格式或修改索引格式时需要变更魔数及读取器。

回归验证分别覆盖索引读取边界、旧包升级/导入包保留/回滚、简繁候选与上屏、联想并发输入。
延迟测量是合成输入到候选装配的耗时，不能替代触摸到屏幕刷新、厂商宿主或 Release 真机验收。
